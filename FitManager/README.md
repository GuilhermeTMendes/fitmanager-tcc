# 🏋️ FitManager — Sistema de Gerenciamento de Academias

O **FitManager** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas da Proz Educação.

A proposta é desenvolver um sistema web para auxiliar no gerenciamento de academias, facilitando a organização de alunos, planos, mensalidades e treinos em uma única plataforma.

## 📌 Sobre o Projeto

Muitas academias ainda utilizam controles manuais ou ferramentas separadas para administrar suas informações. Isso pode dificultar o acompanhamento dos alunos, dos pagamentos e dos planos contratados.

O FitManager surge como uma proposta para centralizar essas informações e tornar a administração da academia mais organizada e prática.

## 🎯 Objetivo

Desenvolver um sistema web intuitivo e organizado que permita gerenciar as principais atividades administrativas de uma academia, facilitando o acesso às informações e o acompanhamento dos alunos.

## 👥 Público-alvo

- Proprietários de academias;
- Administradores;
- Recepcionistas;
- Profissionais responsáveis pelo acompanhamento dos alunos.

## ⚙️ Funcionalidades previstas

- Cadastro, consulta, edição e exclusão de alunos;
- Cadastro e gerenciamento de planos;
- Controle de mensalidades e pagamentos;
- Cadastro e acompanhamento de treinos;
- Painel inicial com informações gerais da academia.
