# FitManager
Projeto de TCC individual de Guilherme Tolentino Mendes — Técnico em Desenvolvimento de Sistemas, Proz Educação.

Sistema web proposto para organizar alunos, planos, mensalidades e treinos de uma academia.

## Tecnologias
HTML5, CSS3, JavaScript, PHP (back-end previsto) e MySQL.

## Pastas
- `frontend/`: interface, estilos e JavaScript.
- `backend/`: reservado para PHP e integração na Semana 4.
- `database/`: script SQL do banco.
- `docs/`: documentação e modelo de dados.
- `prototipos/`: telas planejadas na Semana 2.
- `app/`: organização geral.

## Executar
Abra `frontend/index.html` no navegador ou use Live Server no VS Code.

O cadastro demonstrativo utiliza armazenamento local do navegador (`localStorage`). Ainda não está conectado ao MySQL. A integração será feita na Semana 4.
