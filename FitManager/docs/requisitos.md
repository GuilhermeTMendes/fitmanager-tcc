# Requisitos — FitManager

## Objetivo
Auxiliar no gerenciamento de academias, reunindo informações de alunos, planos, mensalidades e treinos.

## Público-alvo
Proprietários, administradores, recepcionistas e profissionais responsáveis pelo acompanhamento dos alunos.

## Requisitos funcionais
- **RF01:** cadastrar alunos.
- **RF02:** consultar alunos.
- **RF03:** editar dados de alunos.
- **RF04:** excluir alunos.
- **RF05:** cadastrar e consultar planos.
- **RF06:** registrar mensalidades e pagamentos.
- **RF07:** consultar a situação dos pagamentos.
- **RF08:** cadastrar e consultar treinos.
- **RF09:** apresentar indicadores gerais no painel inicial.

## Requisitos não funcionais
- **RNF01:** interface adaptável a diferentes tamanhos de tela.
- **RNF02:** navegação simples e intuitiva.
- **RNF03:** armazenamento em banco de dados MySQL.
- **RNF04:** validação dos dados informados nos formulários.
- **RNF05:** utilização de PHP no processamento do servidor.
- **RNF06:** consultas parametrizadas para reduzir riscos de SQL Injection.
- **RNF07:** código organizado em pastas e arquivos.

## Tecnologias previstas
HTML5, CSS3, JavaScript, PHP, MySQL e Git/GitHub.
