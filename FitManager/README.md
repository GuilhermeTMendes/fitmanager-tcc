# FitManager — Sistema de Gerenciamento de Academias

Projeto de TCC desenvolvido individualmente por Guilherme Tolentino Mendes.

## Objetivo
Organizar informações de alunos, planos, mensalidades e treinos de uma academia.

## Estrutura
- `docs/`: requisitos, arquitetura e diagrama do banco de dados.
- `prototipos/`: protótipos das principais telas.
- `frontend/`: arquivos da interface.
- `backend/`: processamento e acesso aos dados.
- `app/`: espaço reservado para a organização geral da aplicação.

## Tecnologias previstas
HTML5, CSS3, JavaScript, PHP, MySQL e Git/GitHub.

**Etapa:** estrutura inicial e documentação da Semana 2 do TCC.
